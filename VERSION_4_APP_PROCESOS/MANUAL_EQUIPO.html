Manual operativo - Procesos AM V2

Guía actualizada para instalar y usar la aplicación interna de monitoreo de procesos LISTO y cargue de rutas.

Resumen Instalación Monitoreo Cargue de rutas OneDrive Bitácoras Dashboard Diagnóstico Errores comunes Checklist

1. Resumen de la aplicación

Procesos AM V2 es una aplicación de escritorio para el equipo de Soporte. Centraliza dos procesos internos:

Monitoreo procesos LISTO

Valida servidores internos y externos, detecta novedades reales, genera evidencia HTML y resumen para comunicación del equipo.

Cargue de rutas

Lee el archivo Excel enviado por el cliente, limpia datos, valida errores, genera Listo_creditos.csv y deja bitácora del cargue.

La app no reemplaza el criterio humano. Automatiza limpieza, validación y generación de archivos; las diferencias reales deben revisarse con el cliente.

2. Instalación

  1. Ejecutar el instalador INSTALADOR_PROCESOS_AM_V2.exe.
  2. Esperar a que finalice la barra de instalación.
  3. Confirmar que se creó el acceso directo en el escritorio.
  4. Abrir la aplicación desde el acceso directo Procesos AM V2.

El instalador copia la aplicación en el perfil del usuario y crea accesos directos. No es necesario instalar Python en los equipos de los compañeros.

Si Windows bloquea el instalador, usar la opción Ejecutar de todas formas solo si el archivo proviene del equipo autorizado de Soporte.

3. Monitoreo procesos LISTO

Este módulo valida la infraestructura de procesos LISTO. Antes de ejecutar, el equipo debe estar conectado a la VPN o red corporativa.

Opciones principales

Primera revisiónEjecuta la validación de la primera revisión del día.

Primera y segundaEjecuta ambas revisiones de forma consecutiva.

Archivos generados

El archivo detalle_monitoreo.html contiene la evidencia visual del monitoreo. El archivo resumen_estado.txt contiene el resumen para comunicar el estado.

Cuando existan novedades, el detalle del monitoreo las organiza por servidor, base de datos y tipo de alerta para facilitar la revisión.

Las novedades configuradas como excepciones normales no se muestran como alerta. Solo deben aparecer novedades reales que requieran revisión.

4. Cargue de rutas

Este módulo prepara el archivo para cargar créditos en LISTO. El usuario solo debe subir el archivo del cliente; la plantilla interna ya viene incluida en la aplicación.

Flujo recomendado

  1. Entrar al menú Cargue de rutas.
  2. Ingresar Nombre de BD.
  3. Seleccionar si el cargue es Prueba o Producción.
  4. Subir el archivo Excel del cliente.
  5. Revisar el mapeo de columnas detectado por la app. Si el archivo viene con otro formato, la app intenta detectar automaticamente encabezados, fila inicial y columnas equivalentes.
  6. Usar Validar datos para revisar errores, advertencias y duplicados.
  7. Corregir datos si el cliente confirma ajustes.
  8. Usar Procesar cargue para generar el archivo final.
  9. Revisar el resumen ejecutivo generado en Excel para control interno.

Archivo final

C:\Listo\Listo_creditos.csv

Este es el archivo que se carga en el sistema LISTO.

Por cada cargue también se genera un resumen ejecutivo en Excel con total de registros, errores, advertencias, responsable, hora, archivo fuente, archivo final y estado de OneDrive/SharePoint.

Reglas importantes

  • La app limpia tildes, caracteres especiales, puntos y valores con símbolos inesperados.
  • Los archivos del cliente no tienen que venir siempre con el mismo orden de columnas; la app los organiza al formato interno mediante mapeo.
  • Si el cliente envía abonos, se usan los abonos informados.
  • Si el cliente no envía abonos pero sí envía saldo actual, la app reconstruye el abono necesario para cuadrar el saldo.
  • Si hay clientes repetidos, la app no une registros automáticamente. Se debe confirmar si son créditos diferentes o datos duplicados.
  • La fecha de próximo pago puede venir del archivo, calcularse por periodicidad o definirse manualmente para todos o por cliente.
  • Los cargues marcados como Prueba pueden eliminarse desde la app.

5. OneDrive y SharePoint

La aplicación copia resultados en carpetas locales sincronizadas con OneDrive. OneDrive se encarga de subirlos a SharePoint.

Para que funcione correctamente:

  • OneDrive debe estar iniciado con la cuenta corporativa.
  • La biblioteca de SharePoint debe estar sincronizada o agregada como acceso directo a OneDrive.
  • Si OneDrive está pausado, la app puede generar el archivo local, pero no se confirmará la subida.
Si aparece un aviso de que no se encontró la carpeta sincronizada, abrir SharePoint y usar Sincronizar o Agregar acceso directo a OneDrive.

6. Bitácoras y control

La app registra información para trazabilidad del proceso:

BitácoraContenidoUbicación
Bitácora de monitoreo Fecha, hora, revisión ejecutada, estado y salida del proceso. Carpeta local de logs de la app.
Bitácora de cargues Nombre de BD, tipo de cargue, responsable, equipo, IP, archivo cliente, archivo generado, errores y advertencias. OneDrive/SharePoint cuando está sincronizado.

La bitácora no viaja dentro del CSV que se carga a LISTO. Es un control operativo separado.

7. Errores comunes

ErrorCausa probableAcción
VPN no detectada El equipo no tiene acceso a los servidores internos. Conectar VPN y volver a ejecutar.
No se encontró carpeta OneDrive/SharePoint No está sincronizada la biblioteca o se usa otra cuenta. Sincronizar desde SharePoint con la cuenta corporativa.
El campo numérico no puede contener letras El CSV contiene texto en un campo que LISTO espera como número. Volver a validar el cargue y corregir el campo señalado.
Fecha próximo pago menor a la fecha actual El archivo trae una fecha vencida o vacía. Usar fecha manual para todos o ajustar por cliente.
Cliente/documento repetido Puede ser un cliente con varios créditos o un duplicado real. Confirmar con el cliente antes de generar el archivo final.

El Dashboard concentra herramientas generales que no pertenecen a un solo proceso.

9. Diagnóstico para soporte

Desde el Dashboard se puede generar un paquete de diagnóstico cuando la app falle en otro equipo.

Contenido del diagnóstico

  • Versión de la aplicación.
  • Hostname del equipo.
  • Usuario de Windows.
  • IP local detectada.
  • Estado básico de OneDrive.
  • Rutas clave usadas por la aplicación.
  • Configuración local sin secretos.
  • Últimos logs disponibles.
El diagnóstico no incluye archivos originales de clientes ni el CSV final completo.

10. Checklist antes de entregar

  • La app abre desde el acceso directo del escritorio.
  • El botón Abrir manual abre este documento.
  • La VPN está conectada antes del monitoreo.
  • OneDrive está activo y sin pausa.
  • En cargue de rutas se informó el Nombre de BD.
  • Se seleccionó correctamente Prueba o Producción.
  • Los errores bloqueantes fueron corregidos o confirmados.
  • El archivo final quedó en C:\Listo\Listo_creditos.csv.

11. Instalador oficial

Para instalar en otros equipos se debe usar el archivo:

C:\Automatizaciones\procesoAM\INSTALADOR_PROCESOS_AM_V2.exe

Ese instalador contiene la aplicación actual y este manual operativo. Al finalizar valida OneDrive, carpeta corporativa sincronizada y permisos de escritura en la carpeta de control.
