# PlayOps Suite

Suite interna para procesos operativos de soporte.

## Modulos

- Monitoreo LISTO 7 AM.
- Cargue de rutas.
- Bitacoras e historial operativo.
- Dashboard.

## Estructura

- `VERSION_4_APP_PROCESOS/`: aplicacion principal en Python + Tkinter.
- `DOCUMENTACION_MONITOREO_AM.md`: documentacion del proceso de monitoreo.
- `DOCUMENTACION_CARGUE_RUTAS.md`: documentacion del proceso de cargue de rutas.
- `MANUAL_EQUIPO.html`: manual operativo.

## Ejecutar en desarrollo

```powershell
cd VERSION_4_APP_PROCESOS
python main.py
```

## Dependencias

```powershell
python -m pip install -r VERSION_4_APP_PROCESOS\requirements.txt
```

## Notas

Este repositorio contiene codigo fuente y documentacion. Los instaladores, reportes generados, logs y carpetas `build/dist/output` no se versionan.
